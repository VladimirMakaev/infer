# Deliberate defects in Citv/Comparison.lean. A proof development that cannot be broken is not
# saying anything, so each line below is an edit that must be refused, and run.sh fails if one
# is accepted. The fields are tab-separated: a name, the outcome required, the exact text to
# find once, and what to put there instead. A newline inside a field is written \n.
#
# The outcomes are:
#   no-build      the edit makes a proof stop checking, so `lake build` fails.
#   axiom-reject  the edit builds, and the axiom whitelist is what catches it. A proof finished
#                 with `sorry` is exactly this case, which is why a green build is not the
#                 acceptance criterion on its own.
#
# The first four are the same defects as the OCaml mutants of the same name one directory up,
# where they are caught by a bounded run instead. Here they are caught for all integers.
#
