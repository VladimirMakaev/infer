# One deliberate defect per helper of infer/src/pulse/PulseCItv.ml. Each line is three
# tab-separated fields: a name, the exact source text to find once, and what to put there
# instead. A newline inside a field is written \n. run.sh applies one mutant at a time to a
# throwaway copy of the module, runs the oracle, and requires the oracle to reject it.
#
# A mutant that survives is a gap in the oracle rather than a defect in Pulse, so run.sh fails
# on a survivor. If an anchor stops matching after a legitimate change to the module, run.sh
# names it and the mutant has to be rewritten against the new code.
#
