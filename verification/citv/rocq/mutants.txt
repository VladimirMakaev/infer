# One unsound mutation per surviving theorem/arm.  Format: name | target | old ||| new
# Each must (a) still COMPILE, so that a failure is the proof talking and not a broken
# file, and (b) make the proofs be REJECTED.
#
# EIGHTEEN mutants, and MIN_MUTANTS in mutate.sh is 18.  Five aim at abduce_le, four at
# IntLit.v, five at the R4 arithmetic (one per theorem that could otherwise be satisfied
# by a weaker implementation: add, minus's two arms, and binop's two interpreted
# operators), and four at the comparison fragment ported from Lean - abduce_lt's two
# halves, the flip, and the dispatch table.
#
# The four at the bottom RETURN mutants an earlier milestone had and then removed, when
# abduce_lt and abduce_binop_constraints were withdrawn for being proved against a model
# in which IntLit.t was plain Z.  They are back because the theorems are back, over the
# real order and under an explicit hypothesis.  The floor has only ever gone up:
# 4 -> 6 -> 12 -> 16 -> 18.
#
# TWO OBVIOUS MUTANTS ARE DELIBERATELY ABSENT, and the reason is about the code rather
# than about the tests.  Replacing abduce_lt by abduce_le, and dispatching Lt to abduce_le,
# are both SOUND - merely imprecise - so they would survive, and a surviving mutant that is
# really an equivalent mutant teaches nothing and invites someone to weaken a theorem until
# it dies.  A mutant belongs here only if the statement it attacks becomes FALSE.

abduce_le/over-tighten-the-lhs | PulseCItv.v | Satisfiable (Some (between lower1 min_u1u2)) ||| Satisfiable (Some (between (Bound.add_int lower1 IntLit.one) min_u1u2))
abduce_le/over-tighten-the-rhs | PulseCItv.v | (Some (between max_l1l2 upper2)) ||| (Some (between (Bound.add_int max_l1l2 IntLit.one) upper2))
abduce_le/over-tighten-the-between-outside-arm | PulseCItv.v | Bound.max (Bound.Int (IntLit.add IntLit.one u2)) lower1 ||| Bound.max (Bound.Int (IntLit.add IntLit.one (IntLit.add IntLit.one u2))) lower1
